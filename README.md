# wordtrack

wordtrack is a local, offline command-line tool that generates subtitle
files (SRT, VTT, SBV, SSA, or ASS) from a video or audio file, using a
Whisper speech-to-text model that runs entirely on your own machine.
There's no cloud upload, no account, no usage limits, and no watermark.

It exists because consumer apps like CapCut gate automatic captioning
behind a paid plan (a small number of free generations per rolling 30-day
window, then none). wordtrack does the same underlying job — turning
spoken audio into a timed, editable transcript — as a tool that never
runs out and never requires a subscription. It does not burn captions
onto video; it writes a plain subtitle file for you to import into a
video editor and style however you like.

## Requirements

- macOS or Linux
- Python 3
- ffmpeg

You don't need to install these yourself — `install.sh` detects what's
missing and offers to install it for you (via Homebrew on macOS, or
apt/dnf/pacman on Linux), asking for confirmation before anything that
needs `sudo`.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/juliusmarkwei/wordtrack/main/install.sh | bash
```

What this does:

1. Detects your OS and, on Linux, your package manager.
2. Checks for `python3` and `ffmpeg`, offering to install either one if
   it's missing (with a confirmation prompt before any `sudo` command).
3. Downloads the tool's source files into `~/.wordtrack` (override with
   `WORDTRACK_INSTALL_DIR`).
4. Creates a Python virtual environment inside that directory and
   installs wordtrack's dependencies into it — your system Python is
   never touched.
5. Generates a `wordtrack` wrapper script that runs the tool through that
   venv, and symlinks it into `~/.local/bin`.
6. Prints a line to add to your shell profile if `~/.local/bin` isn't
   already on your `PATH`.

Re-running the installer is safe — it just re-downloads the files and
reinstalls the venv in place.

## Usage

```
wordtrack <input-file> [options]
```

| Flag | Type | Default | Description |
|---|---|---|---|
| `<input-file>` | positional, required | — | Path to the video or audio file to caption |
| `--model` | choice: `tiny`, `base`, `small`, `medium`, `large-v3` | `small` | Whisper model size — trade-off between speed and accuracy |
| `--words-per-line` | integer | `1` | Max words per caption cue |
| `--max-gap` | float (seconds) | `0.6` | Max silence allowed inside one cue before it splits into two |
| `--format` | choice: `srt`, `vtt`, `sbv`, `ssa`, `ass` | `srt` | Subtitle output format |
| `--out` | path | `<input file>.<format>` | Output file path |
| `--language` | string | `en` | Spoken language code passed to the model |
| `-h`, `--help` | flag | — | Show usage and exit immediately |

While running, wordtrack shows colored status messages and a live
progress bar during transcription (both are skipped automatically when
output isn't an interactive terminal, or when `NO_COLOR` is set). On
completion, it prints the detected language and the model's confidence in
that detection, the number of caption cues written, and the output path.

### Model sizes

Bigger models are slower but more accurate. Timings below are rough,
CPU-only estimates and will vary with your hardware.

| Model | Parameters | Relative speed | Accuracy |
|---|---|---|---|
| `tiny` | 39M | fastest | lowest — good for quick drafts |
| `base` | 74M | very fast | low-moderate |
| `small` | 244M | moderate (default) | good balance of speed and accuracy |
| `medium` | 769M | slow | high |
| `large-v3` | 1550M | slowest | highest |

### Examples

Caption a video, word-by-word (the default TikTok/Shorts-style captions):

```bash
wordtrack clip.mp4
```

Caption an audio-only file, grouping up to 4 words per cue and splitting
on any silence longer than 0.4 seconds, writing to a specific path:

```bash
wordtrack podcast.mp3 --words-per-line 4 --max-gap 0.4 --out podcast.srt
```

Generate WebVTT instead of SRT:

```bash
wordtrack clip.mp4 --format vtt
```

## Getting bold, animated captions onto your video

wordtrack only produces the subtitle file — it does not touch your video.
To get the bold, word-by-word animated caption look:

1. Open your video project in an editor that supports subtitle import and
   caption styling (e.g. CapCut, VN, Premiere, DaVinci Resolve).
2. Import the file generated by wordtrack as a subtitle/caption track.
3. Apply the editor's caption style (font, color, animation, highlight)
   to that track — this is the step wordtrack intentionally leaves to
   your editor of choice.

## Uninstall

```bash
curl -fsSL https://raw.githubusercontent.com/juliusmarkwei/wordtrack/main/uninstall.sh | bash
```

This removes the `~/.wordtrack` install directory and the `wordtrack`
symlink from `~/.local/bin`.

## Build from source

```bash
git clone https://github.com/juliusmarkwei/wordtrack.git
cd wordtrack
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 wordtrack.py path/to/file.mp4
```

## Troubleshooting

**"file not found" error** — Double-check the path you passed; wordtrack
won't run against a file that doesn't exist, and prints this error
instead of a stack trace.

**Poor transcript accuracy** — Try a larger `--model` (e.g. `medium` or
`large-v3`). Background noise and heavy accents also reduce accuracy at
every model size.

**Slow performance** — Larger models are significantly slower on CPU.
Try a smaller `--model` (e.g. `base` or `tiny`) for faster turnaround, or
expect longer runtimes with `medium`/`large-v3` on longer files.

**`wordtrack: command not found` after install** — `~/.local/bin` isn't
on your `PATH`. The installer prints the exact line to add to your shell
profile when this is the case; add it, then restart your shell (or run
`source ~/.zshrc` / `source ~/.bashrc`).
